# Contributions

Contributions are very welcome! Part of the goal of this project is to help new members of the
community to contribute to mathlib and also grow the intersection of partial differential equations
and formalization.

## The use of generative AI

Using LLMs to generate theorems, definitions or large proofs is not accepted.
Similarly, don't copy verbatim LLM output in discussions.
Using LLMs to refactor existing code is fine.

In doubt, feel free to ask!
